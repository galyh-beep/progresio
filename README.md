# Progresio

Progresio adalah pendamping pencatatan kinerja ASN untuk e-Kinerja: tempel RHK dari SKP, catat kerja harian lewat ketik, suara, atau foto, lalu AI mencocokkannya ke RHK dan hasilnya siap disalin ke e-Kinerja dalam 7 kolom — lengkap dengan rekap, skor kesiapan, kalender, dan arsip ekspor.

Situs: https://galyh-beep.github.io/progresio/

Backend: Cloudflare Workers, dengan data di Google Sheets dan bukti kinerja di Google Drive.
