Skor kesiapan

Per RHK · tiap kotak = 1 bulan (Jan–Des)

Rumus skor: per RHK = jumlah bulan berjalan yang punya minimal 1 bukti ÷ jumlah bulan berjalan × 100. Skor total = rata-rata semua RHK.

Data di perangkat ini

—

Entri, RHK, profil, dan pengaturan — termasuk kunci GAS/Gemini, ID folder Drive tujuan eviden, dan token Telegram — tersimpan di localStorage perangkat ini dan dimuat lagi saat aplikasi dibuka. Lampiran tersimpan sebagai metadata (nama, ukuran, tipe) plus thumbnail kecil untuk foto; isi berkasnya perlu dilampirkan ulang setelah aplikasi dibuka kembali.

Bila kunci Gemini terisi, catatan ketik & suara diproses Gemini langsung dari peramban ini — failover 3 model, urutan kelancaran: utama gemini-3.5-flash-lite, cadangan gemini-3.1-flash-lite, terakhir gemini-3.8-flash (bisa diganti di wizard Koneksi): teks dirapikan, jam mulai–selesai dan jumlah realisasi diekstrak mengikuti Satuan & Aturan Hitung RHK, durasi dihitung ulang dari jam oleh kode, lalu catatan dicocokkan semantik ke RHK. Hasilnya menjadi kartu draf dulu — tombol Simpan draf baru aktif bila jam mulai–selesai lengkap. Bila tidak ada RHK yang benar-benar cocok, entri ditandai “belum terpetakan” — tidak dikarang — dan bisa dipetakan manual dari halaman entri. Tanpa kunci atau saat Gemini tak terjangkau, pencocokan kata kunci lokal di perangkat menjadi cadangan. Sinkron backend — entri, RHK & profil ke Sheets, eviden ke folder Drive, link folder asli di kolom 7 — diatur dari kartu Koneksi Worker di atas; Telegram menyusul di fase berikutnya. Data tersimpan di localStorage perangkat ini.
